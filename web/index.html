一句话：测「大跌时把一部分钱换成杠杆 ETF、大涨后再换回来」长期比死拿多赚多少、多扛多少回撤。
最快上手：点 填入推荐参数 → 点 运行回测，先看结果再回来看规则。
⚠️ 本策略放大下跌、不保护下跌，参数基于历史最优存在过拟合，不构成投资建议。
策略只有两条规则
  • 回撤补仓（越跌越上杠杆）：基准端（如 SMH）从历史最高点跌到 -15%/-25%/-35%… 某一档时，卖掉当时基准端市值的指定比例，全部买入杠杆端（如 SOXL）。每档在同一轮下跌中只触发一次。
  • 反弹减仓（涨回来就落袋）：基准端从「有效底部」反弹 +50%/+100%/+200% 某一档时，卖掉当时杠杆端市值的指定比例，换回基准端。
  • 有效底部＝本轮自高点回撤超过 25% 后出现的最低价。小幅回调不算新底部，避免刚跌一点就被误判成「抄到底」。
四步跑出第一个结果
  1. 选数据源：SMH/SOXL（半导体 3 倍）、QQQ/TQQQ（纳指 3 倍）、SMH/USD（半导体 2 倍）。
  2. 填投入金额：基准端与杠杆端各投多少美元，默认各 5 万。
  3. 设置档位百分比：不确定填多少就直接点 填入推荐参数（该数据源近 10 年收益最优的网格搜索结果）。填 0 表示这一档不操作。
  4. 点 运行回测。改任何参数后重新点一次即可。
结果怎么看
  • 参数区的状态条与小字：显示当前最新价、距峰值跌幅、距有效底部涨幅，以及每一档还要跌/涨到多少钱才会触发——这是把回测结论用到实盘的地方。
  • 关键指标：最终总资金、CAGR 年化、最大回撤（越小越好）、夏普、最长套牢天数。
  • 净值曲线：动态策略 vs 50-50 不动 vs 纯持基准 vs 纯持杠杆，四条线同口径对比；红三角＝补仓、绿箭头＝减仓；鼠标悬停看当日各条曲线数值与当日成交价。资金差距过大时勾上「对数坐标」更易读。
  • 组合横向对比：同一区间内几组标的谁更强。
  • 逐笔交易明细：每次换仓的日期、方向、换了多少钱、当天两端的成交价（本模型按当日收盘价成交）、成交后总资金。
  • 进场建议（页面最底部）：按当前选中组合的真实状态，给出此刻两端配比与之后各档的触发价与金额。
  • 每月定投（运行回测那一栏的勾选框）：勾上后每月第一个交易日注入「起始资金的 1%」全额买入基准端，四条对比曲线用同一现金流。此时点「填入推荐参数」会填入按定投口径重新网格搜索出的加减仓比例（参数区下方会列出与一次性投入的差异），指标也换成 XIRR / TWR + 累计投入、净盈亏，因为陆续投钱时净值倍数已不可比。勾选框右侧会显示截止回测末日的累计定投总额（期数 × 每月金额）以及「起始本金 + 定投 = 累计投入」。
必须知道的三点（风险）
  • 本策略放大下跌、不保护下跌：越跌越加杠杆，极端行情下可能在最低点满仓杠杆，回撤远大于纯持基准。
  • 参数是在历史数据上找最优，存在过拟合，未来不会原样重现。
  • 在线版行情为发布时的快照；想抓最新数据请克隆仓库后用 python web/serve.py 本地运行。结果仅为研究用途，不构成投资建议。

进场建议：此刻入场怎么买、什么价位买

以当前数据源的最新交易日收盘价为进场价，在上方「补仓/减仓参数」保持不变的前提下， 从历史上与当下同阶段（同为创新高 / 高位回调 / 深度回撤探底 / 底部反弹，且回撤或反弹幅度接近） 的若干个日期分别起算，逐一回测不同的「初始杠杆端占比」，挑出未来表现最优的配比。 价位清单沿用策略真实状态（历史峰值 / 本轮有效底部 + 本轮已触发档）， 与上方「补仓/减仓触发价」完全一致，可直接对照执行。
