# 杠杆 ETF 补仓减仓策略回测工具

一个用于研究「基准 ETF ↔ 杠杆 ETF 轮动」策略的回测工具，提供 **桌面 GUI**（Python + tkinter）和 **浏览器版**（纯静态页面，可在线打开）两种形态。

> **在线体验**：https://fanruihwaiting8.github.io/SMHDataAnalysis/

## 策略模型

资金在「基准标的」与「杠杆标的」之间双向转换，全程满仓、不留现金，以份额记账：

- **回撤补仓**：基准标的自历史新高回撤达到 15% / 25% / 35% / 45% / 50% 档位时，卖出当前基准持仓市值的指定百分比，全部换入杠杆标的。创新高后基准上移、各档位重新计数。
- **反弹减仓**：基准标的自「有效底部」反弹达到 50% / 100% / 200% 档位时，卖出当前杠杆持仓市值的指定百分比，全部换回基准标的。
- **有效底部**：建仓日价格即为初始底部；此后每当某一段（两个相邻新高之间）回撤达到 25%，即以该段区间最低价作为新底部，段内继续下探则底部跟随下移。

每档比例均可自行填写，便于横向比较不同激进程度的参数。

## 内置标的组合

| 组合 | 基准 | 杠杆端 | 说明 |
| --- | --- | --- | --- |
| 半导体 | SMH | SMH3 | SMH3 为伦敦上市 3 倍半导体 ETP，数据自 2021-12 起 |
| 纳指 | QQQ | TQQQ | 3 倍纳指，数据口径最干净，推荐优先用于调参 |
| 半导体·2 倍 | SMH | USD | USD 为 ProShares Ultra Semiconductors，数据自 2007 起 |

回测起点取两份数据的共同交易日首日。

## 运行方式

### 浏览器版（推荐，零依赖）

```bash
python3 web/serve.py
```

会自动起一个本地服务并打开页面。行情数据内嵌在 `web/data.js`，页面内「更新最新数据」按钮会联网重抓并重建数据（仅本地运行时可用；在线版为发布时快照）。

### 桌面 GUI 版

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

macOS 也可用 `./run_smh.sh` 启动（自动处理 Apple Silicon 架构问题）。

额外工具：

- `compare.py` —— 三组组合的九条净值曲线对比看板
- `update_data.py` —— 一次性刷新 `Input/` 下全部标的的历史 CSV
- `optimize_*.py` / `walk_forward.py` —— 参数网格搜索与滚动前推检验

## 环境要求

- Python 3.9+
- 浏览器版无第三方依赖（图表走 CDN 的 ECharts）
- 桌面版需要 `matplotlib`，以及随 Python 一起安装的 `tkinter`

## 数据来源

历史行情通过公开接口抓取，仅用于个人研究：

- QQQ / TQQQ / SMH3 / USD：FT Markets 历史价格接口
- SMH：Nasdaq 官方接口（仅覆盖近 10 年）

数据均为原生美元计价，不做汇率换算。各接口口径、复权方式存在差异，数值与官方页面可能有千分之几的偏差。若接口变更导致抓取失败，请自行替换为其他数据源——CSV 格式为 `Date,Open,High,Low,Close,AdjClose,ChangePct,Volume`。

## 已知局限

- 回测**不计入**交易手续费、买卖价差、税费与杠杆 ETF 的日内复利损耗（volatility decay），实际收益会显著低于回测值。
- 本策略**放大下跌、不保护下跌**：越跌越加杠杆，极端情况下会在最低点满杠杆持仓。
- SMH3 数据仅自 2021-12 起，所谓「十年回测」实际约 4.8 年，样本极少，参数过拟合风险很高。
- 夏普比率未扣除无风险利率，仅供工具内部横向比较。
